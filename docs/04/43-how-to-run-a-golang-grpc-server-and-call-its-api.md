# How to run a golang gRPC server and call its API

在 main.go 寫 func runGrpcServer ，改用 grpc server

install evans cli <https://github.com/ktr0731/evans?tab=readme-ov-file#macos> ，這是一個好用的 grpc client

啟動 evans cli <https://github.com/ktr0731/evans?tab=readme-ov-file#basic-usage> `evans --host localhost --port 9090 -r repl`
