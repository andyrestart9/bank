# Generate DB documentation page and schema SQL dump from DBML

## Generate DB documentation page

Install dbdocs via terminal <https://docs.dbdocs.io/#1-install-dbdocs-via-terminal>

Define your database with DBML <https://docs.dbdocs.io/#2-define-your-database-with-dbml> ref: doc/db.dbml

Login to dbdocs <https://docs.dbdocs.io/#3-login-to-dbdocs>

Generate dbdocs project <https://docs.dbdocs.io/#4-generate-dbdocs-project>

Password protection <https://docs.dbdocs.io/features/project-access-control#password-protection>

## How to generate the SQL codes directly in the terminal

Install DBML CLI <https://dbml.dbdiagram.io/cli#installation>

Use dbml2sql generate SQL codes from dbml <https://dbml.dbdiagram.io/cli#convert-a-dbml-file-to-sql>
